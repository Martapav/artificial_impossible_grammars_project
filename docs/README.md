# Documentation

- [RECIPE_SELECTION.md](RECIPE_SELECTION.md) — the grid sweep, the selection

- [CH2_SUB3_CLAUSE_SWAP_TESTS.md](CH2_SUB3_CLAUSE_SWAP_TESTS.md) — what each test in the
  H′/P′ clause-swap analysis does and why.
